# Citation

This repository is an external Slurm orchestration wrapper around CBIcall.

Please cite CBIcall when using the underlying genomic workflows:

Rueda M, Fernandez-Orth D, Gut IG. **CBIcall: a configuration-driven framework for variant calling in large sequencing cohorts.** *Bioinformatics Advances*. 2026. doi:10.1093/bioadv/vbag232.

- CBIcall repository: https://github.com/CNAG-Biomedical-Informatics/cbicall
- CBIcall documentation: https://cnag-biomedical-informatics.github.io/cbicall/
