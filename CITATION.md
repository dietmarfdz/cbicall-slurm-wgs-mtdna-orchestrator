# Citation

If you use this repository in a scientific or technical workflow, please cite both this orchestration repository and the underlying CBIcall software.

## This repository

Fernández Orth D. **CBIcall WGS + mtDNA Slurm Orchestrator**. GitHub repository, 2026.

Repository:  
https://github.com/dietmarfdz/cbicall-slurm-wgs-mtdna-orchestrator

This repository provides an external Slurm orchestration and monitoring layer for sequential CBIcall WGS and mitochondrial DNA analyses, including validation checkpoints, mtDNA failure diagnostics, batch execution, status monitoring, and fail-safe cleanup.

## CBIcall

The genomic analyses are performed by CBIcall. Please also cite:

Rueda M, Fernandez-Orth D, Gut IG. **CBIcall: a configuration-driven framework for variant calling in large sequencing cohorts.** *Bioinformatics Advances*. 2026. doi:10.1093/bioadv/vbag232.

CBIcall repository:  
https://github.com/CNAG-Biomedical-Informatics/cbicall

CBIcall documentation:
